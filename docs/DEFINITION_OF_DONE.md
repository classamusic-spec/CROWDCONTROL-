## Non-blocking limitations (documented)
- Raster character/environment art is **original procedural/SVG** at runtime
  (Asset Mode B); raster upgrades are queued with exact prompts in
  `docs/ASSET_GENERATION_QUEUE.md`. The app is visually complete without them.
- Audio is **silent placeholder** wiring; SFX queued in
  `docs/AUDIO_GENERATION_QUEUE.md`.
- No device screenshots captured in the build environment; capture list in
  `docs/MANUAL_VISUAL_QA.md`.

## Developer credentials still required (for store submission)
- Apple Developer account + `bundleIdentifier` ownership (placeholder
  `com.yourstudio.crowdcontroldaily`).
- Google Play account + package name ownership.
- EAS project id / signing credentials (generated by `eas build`, not invented
  here).
